CoreOps

An AI operations platform for SQL Server, SSIS, and SSRS, with a governed, human-approval execution model.

Live in production · coreops.fly.dev
Problem

Troubleshooting is slow, manual, and scattered across systems.

Database administrators and ops teams correlate failures across SQL Server, SSIS packages, and SSRS reports by hand. A job fails at 2am, a report comes back empty at 8am, and the next hour goes to reconstructing what happened from a dozen different tools.

~20 hrs
a week spent troubleshooting, from JIRA time logged on troubleshooting tickets
Solution

Monitor, diagnose, and remediate, with a human always in the loop.

What it does
  • Reads live SQL Server DMVs, SSRS execution logs, cloud and Postgres signals
  • Uses Claude to explain the likely root cause, citing only evidence it was actually given
  • Proposes a source-specific fix, checked against fixed safety rules first
  • Runs nothing until an authenticated human approves, then confirms the outcome independently
Who it's for
Database administrators and ops teams.
What it can really change today
  • End a blocking Postgres session
  • Restart a demo service container through Fly.io's API
  • SQL Server, SSRS, and cloud fixes: real recommendation, simulated execution, labelled as simulated everywhere

No action is ever taken without authenticated human approval.
