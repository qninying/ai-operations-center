Root Cause — explained by Claude

A scheduled index rebuild on dbo.SalesFact started at 01:33 and was still holding a lock at 02:14, well past its usual 15-minute window. The nightly Load_DailySales SSIS package tried to write to the same table, waited the full 30-minute timeout, and failed. The index rebuild is the root event — the SSIS failure is a downstream symptom, not a separate problem.
