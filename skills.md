# Skills used to build this project

This blueprint was generated by [`BuildIdeaPrompt.txt`](BuildIdeaPrompt.txt) driving three Claude Code skills in sequence, each reading the previous one's output. The skills themselves live in the parent repository's `.claude/skills/` (not duplicated here, since they're generic and reusable across projects, not specific to the AI Operations Center).

## 1. `system-architect`

**Input:** a one-paragraph project idea (the AI Operations Center description).
**Output:** [`project-blueprint/architecture.md`](project-blueprint/architecture.md) — derives the component list strictly from words in the idea paragraph, draws a Mermaid flowchart of how components connect, walks the data flow, lays out a build order, and states assumptions plus what's explicitly not covered.

## 2. `tech-stack-recommender`

**Input:** `architecture.md`.
**Output:** [`project-blueprint/tech-stack.md`](project-blueprint/tech-stack.md) — one real, current technology per component, fit-rated (🟢/🟡/🔴) against this project's actual scale and the likely skill set of the team, with alternatives considered and an undo-cost ranking.

## 3. `mvp-scoper`

**Input:** `architecture.md` + `tech-stack.md`.
**Output:** [`project-blueprint/mvp-plan.md`](project-blueprint/mvp-plan.md), [`project-blueprint/mockup.html`](project-blueprint/mockup.html), and [`project-blueprint/one-pager.pdf`](project-blueprint/one-pager.pdf) — the smallest real Week 1 build that tests the riskiest assumption (can Claude produce a trustworthy root-cause explanation at all) before any real infrastructure exists, plus a visual mockup of the main screen and a one-page pitch.

## The knowledge-base site itself

The multi-page site (`index.html` and the numbered section pages, plus the `mvp/` and `stack/` companion mini-sites) was hand-built per the detailed spec in `BuildIdeaPrompt.txt` — not a named skill, but the same prompt that kicked off the `system-architect` run. It's plain HTML/CSS/vanilla JS with no build step, so it opens directly from disk.

## Not used for this project

`skill-lab/` and the other Claude API example scripts in the parent repository (`workflow_assistant.py`, `eval_harness.py`, etc.) are unrelated teaching examples from a different exercise — they didn't contribute to this blueprint and weren't moved here.
